**Цели:** экран горит — 3–4 ч и больше (оригинал со слов автора ~1 ч); ожидание с подключённым iPhone — в 2–3 раза

## Этап 0. Подготовка (без платы) — ✅
- [x] Форк на GitHub (`kimigg1/Pip-KeyPet`), `upstream` — оригинал автора
- [x] ESP-IDF 5.5.5 на Windows, сборка оригинальной прошивки
- [x] Симулятор собирается на Windows, `sim/check.py` зелёный (ветка `windows-build`)

## Этап 1. Замер «до» (когда придёт плата)
- [ ] Прошить оригинал (1.1.0), замерить журналом `bat`: экран горит постоянно; обычное использование;
      ожидание с iPhone и без
- [ ] Команда `pm`: что держит чип бодрствующим в каждом сценарии
- [ ] Записать результаты сюда — это база для сравнения

## Этап 2. Экран горит (основной расход)
- [ ] **Не перерисовывать неподвижное лицо.** Если за кадр глаза сдвинулись меньше ~0,5 px — кадр не рисуется.
      Отсечь шум акселерометра (мёртвая зона наклона), чтобы глаза не дрожали от него. *(можно делать в симуляторе)*
- [ ] **Чип спит между кадрами при горящем экране.** AMOLED сам держит картинку; 240 МГц — только на время
      отрисовки, в остальное время light sleep. Сейчас при горящем экране чип не спит вообще. Главная экономия.
- [ ] **30 кадров/с по умолчанию**, 60 — только для быстрого (моргание, испуг, тряска, игры). *(симулятор)*
- [ ] **Яркость по умолчанию 60%** вместо 80%; приглушение через 10 с без касаний.
- [ ] *(по желанию)* Глаза чуть сероватые вместо чисто белых — проверить глазами, заметно ли.

## Этап 3. Bluetooth
- [ ] Реклама: быстро первые 30 с после включения/разрыва, потом ~раз в секунду (сейчас — быстро и всегда)
- [ ] С iPhone в покое — редкий интервал связи (~100–200 мс + пропуски), быстрый только в пульте/мыши/музыке.
      Уведомления должны приходить с задержкой < 1 с
- [ ] Режим «без iPhone»: Bluetooth выключен полностью, включается из меню

## Этап 4. Датчики и звук
- [ ] Микрофон — порциями и только когда на экране лицо
- [ ] Гироскоп — только в лабиринте и пульте; акселерометр в экономном режиме при погашенном экране
- [ ] Опрос датчиков при погашенном экране 10 раз/с вместо 50 (FIFO датчика)
- [ ] Тач-контроллер в сон при погашенном экране

## Этап 5. Экран погашен и ночь
- [ ] Экран в deep standby вместо «display off» (0x28)
- [ ] *(по желанию)* Ночной режим: долго без движения ночью → полное выключение через AXP2101; при включении время
      от iPhone (CTS), Пип «проживает» пропущенное. Минус: ночью нет уведомлений, будить кнопкой

## Этап 6. Зарядка, настройки, итог
- [ ] Ток зарядки под аккумулятор (500 мАч → ~250 мА, настраиваемый, если поставим больше)
- [ ] Один переключатель «Экономия / Обычный / Максимум» в панели настроек
- [ ] Замер «после» по сценариям этапа 1, сравнение с оригиналом

## Потом (если не хватит)
- [ ] Аккумулятор 103035 (~1000 мАч) в напечатанной задней крышке — после замеров и обмера корпуса

## Риски
- Тач может откликаться чуть медленнее; уведомления — с небольшой задержкой
- Light sleep при горящем экране: проверить, что не моргает картинка и не теряются касания/кнопки
