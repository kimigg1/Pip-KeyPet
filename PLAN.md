## Этап 2. Экран горит (основной расход)
- [ ] **Не перерисовывать неподвижное лицо.** Если за кадр глаза сдвинулись меньше ~0,5 px — кадр не рисуется.
      Отсечь шум акселерометра (мёртвая зона наклона), чтобы глаза не дрожали от него. *(можно делать в симуляторе)*
- [ ] **Чип спит между кадрами при горящем экране.** AMOLED сам держит картинку; 240 МГц — только на время
      отрисовки, в остальное время light sleep. Сейчас при горящем экране чип не спит вообще. Главная экономия.
- [ ] **60 кадров/с остаются** (моё решение: плавность важнее). Экономим не снижением частоты, а тем, что
      неподвижные кадры не рисуются и чип спит между кадрами. Меньше кадров — только в режиме «Экономия»,
      если я сам его выберу (как эко-режим оригинала, ≤20 кадров/с)
- [ ] **Яркость по умолчанию 60%** вместо 80%; приглушение через 10 с без касаний.
- [ ] *(по желанию)* Глаза чуть сероватые вместо чисто белых — проверить глазами, заметно ли.

## Этап 3. Bluetooth
- [ ] Реклама: быстро первые 30 с после включения/разрыва, потом ~раз в секунду (сейчас — быстро и всегда)
- [ ] С телефоном в покое — редкий интервал связи (~100–200 мс + пропуски), быстрый только в пульте/мыши/музыке.
      Уведомления должны приходить с задержкой < 1 с
- [ ] Режим «без телефона»: Bluetooth выключен полностью, включается из меню

## Этап 4. Датчики и звук
- [ ] Микрофон — порциями и только когда на экране лицо
- [ ] Гироскоп — только в лабиринте и пульте; акселерометр в экономном режиме при погашенном экране
- [ ] Опрос датчиков при погашенном экране 10 раз/с вместо 50 (FIFO датчика)
- [ ] Тач-контроллер в сон при погашенном экране

## Этап 5. Экран погашен и ночь
- [ ] Экран в deep standby вместо «display off» (0x28)
- [ ] *(по желанию)* Ночной режим: долго без движения ночью → полное выключение через AXP2101; при включении время
      от телефона (Gadgetbridge, этап 7), Пип «проживает» пропущенное. Минус: ночью нет уведомлений, будить кнопкой

## Этап 6. Зарядка, настройки, итог
- [ ] Ток зарядки под аккумулятор (500 мАч → ~250 мА, настраиваемый, если поставим больше)
- [ ] Один переключатель «Экономия / Обычный / Максимум» в панели настроек
- [ ] **Прогноз заряда:** «осталось ~N ч» на экране (часы, уход за Пипом) — по журналу батареи и текущему режиму
- [ ] **Автоэкономия:** при 20% заряда Пип сам включает «Экономию» (и говорит об этом), на зарядке возвращает
      прежний режим. Порог настраивается в панели
- [ ] Замер «после» по сценариям этапа 1, сравнение с оригиналом

## Этап 7. Android (у меня не iPhone)

- [ ] Bluetooth-экономия этапа 3 — с учётом Gadgetbridge (редкий интервал связи в покое)

## Этап 8. Новые функции (через Gadgetbridge) — все хочу
- [ ] **Погода:** Gadgetbridge присылает погоду (`t:"weather"`) → показывать на часах, и Пип реагирует
      (в дождь — тучка с дождём над ним, она уже есть в `ui/doodle.c`; жара/холод — свои реакции)
- [ ] **Найти брелок:** кнопка в Gadgetbridge (`t:"find"`) → Пип пищит и мигает, пока не нажмёшь кнопку
- [ ] **Найти телефон:** действие на брелоке → телефон звонит (сообщение `{t:"findPhone"}` в Gadgetbridge)
- [ ] **Будильники с телефона:** Gadgetbridge передаёт будильники (`t:"alarm"`) → Пип будит своей мелодией
      (мелодия таймера уже есть), будильник работает и без связи с телефоном

- [ ] **Шаги и заряд брелока в Gadgetbridge:** Пип отдаёт телефону шаги (графики активности) и свой заряд

## Этап 8Б. Удобство и приложения
- [ ] **Постучать по корпусу:** двойной стук (детектор стука QMI8658, без постоянного опроса) → экран
      просыпается и показывает время, трогать экран не нужно
- [ ] **Виджеты на часах:** шаги, погода, заряд (и прогноз), ближайший будильник
- [ ] **Помодоро-таймер:** 25 мин работа / 5 мин перерыв, Пип подбадривает и радуется законченным подходам
- [ ] *(по желанию, выключено по умолчанию)* **Часы всегда на экране:** тусклые цифры на чёрном (режим низкого
      потребления экрана CO5300), сдвигать цифры, чтобы не выгорал AMOLED. Сначала замерить, сколько ест

## Этап 9. Голосовой Пип с нейросетью (после батареи и Android)
Нейросеть в облаке, не на брелоке. Начинать только после этапов 2–8 и замеров, чтобы не мешать батарее.
- [ ] **Проверка памяти:** влезает ли Wi‑Fi рядом с Bluetooth и LVGL во внутреннюю RAM (~80 КБ свободно).
      Буферы Wi‑Fi/lwIP — в PSRAM, если можно. Без урезания функций Пипа
- [ ] **Разговор по кнопке:** зажал кнопку → запись с микрофонов → в облако → ответ голосом через динамик.
      Wi‑Fi включается только на время разговора (домашний или раздача с телефона)
- [ ] **Свой маленький сервер-посредник:** брелок говорит только с ним; ключи API не хранятся в брелоке,
      нейросеть можно поменять без перепрошивки
- [ ] **Цепочка:** распознавание речи → нейросеть → озвучка. Claude/ChatGPT API официально недоступны в России —
      смотреть YandexGPT или GigaChat (ответы) и Yandex SpeechKit (речь ↔ текст). Посмотреть, как сделано
      в открытом XiaoZhi AI (эта плата у Waveshare заявлена как совместимая)
- [ ] **Эмоции от нейросети:** вместе с ответом нейросеть выбирает одну из 45 эмоций Пипа — он говорит с этим лицом
- [ ] **Характер:** системная подсказка — Пип отвечает коротко, в своём характере, по-русски
- [ ] *(идеи)* пересказ уведомлений, короткие фразы на экране, память о прошлых разговорах
- [ ] Замер: сколько заряда съедает один разговор
